# Itqan Academy — Visual Identity

The audience is Arabic-first, mostly on phones, often on modest connections, and
the subject is the Quran. Everything below follows from that: legible Arabic
before decorative Arabic, calm colour before loud colour, and assets small
enough that the brand never costs a student a slow page.

---

## 1. The mark

The mark is the **Rub' el Hizb** (`۞`) — the eight-pointed star printed in the
margins of the mushaf to mark each quarter of a *hizb*. Anyone who has memorised
from a printed Quran recognises it instantly, and it says "measured progress
through the text", which is exactly what this platform tracks.

Geometrically it is two overlapping squares, one rotated 45°, with softened
joints and a circular void at the centre. That construction fixes the
proportions: with the star tips at radius `R`, the valleys sit at
`r = 2·sin(22.5°)·R ≈ 0.765·R`. Nothing about the shape is arbitrary.

**Do**
- Keep the clear space around the mark at least equal to one star point (12% of
  its width).
- Use the gradient version on light surfaces, the flat white version on brand
  green or photographs, the ink version for single-colour print.
- Scale it freely — it was drawn on a 512-unit grid and stays legible at 16px.

**Don't**
- Rotate it. The top point is always vertical.
- Recolour it outside the palette below, add a stroke, or fill the centre void
  with anything but the surface behind it.
- Stretch it. The mark is square.

### Files

| File | Use |
|---|---|
| `public/brand/mark.svg` | Primary, gradient, transparent background |
| `public/brand/mark-light.svg` | White, for dark or photographic backgrounds |
| `public/brand/mark-ink.svg` | Single-colour `#12382C`, for print |
| `public/brand/mark-tile.svg` | On the deep-green tile, for app icons |
| `public/brand/lockup-ar.svg` | Mark + Arabic wordmark, mark on the right |
| `public/brand/lockup-en.svg` | Mark + English wordmark, mark on the left |
| `src/components/brand-mark.tsx` | In-app React component (inline, no request) |

All of them — plus every icon below — are generated by one script:

```bash
npm run brand:assets
```

Change the geometry or colours in `scripts/generate-brand-assets.mjs` and rerun
it; the favicon, the PWA icons and the SVGs can never drift out of sync because
they all come from the same path definition.

### Lockups and direction

In Arabic the mark sits to the **right** of the wordmark; in English, to the
**left**. The reading eye should meet the mark first in both languages. The app
header does this automatically — the layout uses flex order, not hardcoded
sides, so `dir="rtl"` flips it without a second stylesheet.

## 2. Colour

### Sidr green — primary

Named for the lote tree. It is the green of the manuscript tradition rather than
the saturated green of a flag, which keeps the interface calm across long
sessions.

| Token | Hex | Where it is used |
|---|---|---|
| `brand-50` | `#EDF7F2` | Tinted card backgrounds |
| `brand-100` | `#D3ECE0` | Badges, selection highlight |
| `brand-200` | `#A8D9C2` | Borders on tinted cards, focus rings |
| `brand-300` | `#75C0A0` | Decorative only |
| `brand-400` | `#45A57F` | Gradient start, dark-mode accents |
| `brand-500` | `#2A8A66` | "Present" status |
| `brand-600` | `#1E6E51` | **Primary buttons, links, focus outline** |
| `brand-700` | `#1A5842` | Button hover, wordmark, gradient end |
| `brand-800` | `#164636` | Text on `brand-100` |
| `brand-900` | `#12382C` | Ink logo |
| `brand-950` | `#0A231B` | App-icon tile |

### Dhahab gold — accent

Gold appears **only** on the student whose turn it is to recite. That scarcity
is the whole point: when a teacher glances at a queue on a phone, exactly one
row is gold, and it is the row that matters. Using it for anything else destroys
the signal.

| Token | Hex |
|---|---|
| `accent-100` | `#F7EDD6` |
| `accent-300` | `#E3C37C` |
| `accent-500` | `#C4913A` |
| `accent-700` | `#7E5A24` |

### Status colours

| Meaning | Token | Hex |
|---|---|---|
| Present | `present` | `#2A8A66` |
| Absent | `absent` | `#C0453B` |
| Reciting now | `reciting` | `#C4913A` |
| Waiting | — | muted foreground on `surface-muted` |

Status is never carried by colour alone — every badge carries a label, because
colour-blind users and bright-sunlight phone screens both fail on hue.

### Surfaces

Light and dark are both first-class; the tokens swap under
`prefers-color-scheme`.

| Token | Light | Dark |
|---|---|---|
| `background` | `#F6F9F7` | `#08130F` |
| `surface` | `#FFFFFF` | `#0F1E18` |
| `surface-muted` | `#EDF2EF` | `#152720` |
| `foreground` | `#0E1F19` | `#E6EFEA` |
| `muted-foreground` | `#5A6E66` | `#93A9A0` |
| `border-subtle` | `#DBE5E0` | `#21352C` |

Body text on `background` clears WCAG AA in both schemes; `brand-600` on white
and `brand-100` on `brand-800` do as well. Check any new pairing before shipping
it.

## 3. Typography

| Role | Family | Notes |
|---|---|---|
| Interface | **Cairo** | Arabic + Latin in one family, so a language switch never changes the texture of the page. Loaded as `--font-cairo`, exposed as `font-sans`. |
| Display | **Amiri** | Classical Naskh for the wordmark and page headings. Loaded as `--font-amiri`, exposed as `font-display`. |

Both are served through `next/font/google`, so they are self-hosted at build
time — no request to Google at runtime, no layout shift, and no dependency on a
third party for a page a student opens five minutes before a circle starts.

**Rules**

- `font-display` is for `h1` and the wordmark only. Amiri at small sizes is
  harder to read on a phone than Cairo; body copy stays Cairo everywhere.
- Never set Arabic below 16px. Diacritics disappear.
- Never letter-space Arabic — it breaks the joins between letters.
- Student and circle names are user data: render them as entered, in whichever
  script the person used, and never transliterate.
- Digits stay Western (1, 2, 3) in both locales so queue positions are scannable
  by teachers who switch languages.

## 5. Voice

Arabic is the default language and the primary voice; English is a faithful
translation, not a separate personality.

- Address students directly and plainly. No honorific inflation, no marketing
  register.
- Prefer the concrete: "ابحث عن اسمك" over "ابدأ رحلتك".
- Errors say what happened and what to do next, in one sentence.
- Never invent religious framing the academy has not asked for. The product
  organises circles; it does not preach.

---

## 6. Layout

- **Mobile-first.** Design at 360px, then let it breathe. Most students open the
  circle page on a phone minutes before it starts.
- **Direction-agnostic.** Use logical utilities (`ms-`, `me-`, `ps-`, `pe-`,
  `text-start`, `border-s`) everywhere. A hardcoded `ml-4` is a bug: it will be
  on the wrong side in one of the two languages.
- **Touch targets ≥ 44px.** Attendance and recitation are one-tap actions a
  teacher performs repeatedly while listening.
- Content column caps at `max-w-4xl`; cards use `rounded-2xl` and a single soft
  shadow. Depth is not part of the identity.
